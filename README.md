# Initial Creationg
- `poetry new python_base`
- `cd python_base`
- `poetry install`

# VSCode Setup
## Interpreter
1. `ctrl`+`shift`+`p`
2. Type `Python: Select Interpreter`.
3. Select `./.venv/bin/python`.
## Testing
1. Select Testing tab.
2. Select Configure Python Tests.
3. Select pytest.
4. Select tests.
